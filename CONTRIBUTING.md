# Contributing

The Streamer.bot C# files are standalone action bodies, not a conventional .NET project. Please identify which action was changed and include steps for testing it in Streamer.bot. Do not commit Twitch tokens, broadcaster identifiers, exported viewer data, or other private configuration.

For changes to trigger names, command setup, or persistent variable semantics, update `docs/INSTALLATION.md` and `README.md` in the same change.
